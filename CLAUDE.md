## v3.47.0 (2026-08-12) — scenarios + downgrade gate

- **Any number expressed "from here" must re-anchor as "here" moves.**
  Static from-current returns authored at Phase-5 entry double-count once
  drawdown is realized. Anchor to invariants (peak-to-trough bands),
  derive from-here at render time, enforce ordering.
- **If one case is deterministic, all cases must be** — mixing one
  re-anchored number with LLM-authored siblings produced bear-better-
  than-base. Half-determinism is scramble by construction.
- **Prompt guards decay; gates do not.** The Aug-12 downgrade recurred on
  the exact indicator the v3.39.7.3 INVALID-DOWNGRADES section names.
  Every prompt rule protecting persistent state needs a deterministic
  code twin (ratchet / reversal gate) at both legs.
- **Downgrades need a citable reversal**, not a quiet or partial news
  day: the REVERSAL: token makes de-escalation auditable and greppable.
- **Derived integers must come from their source fields** — "trough in
  0mo" beside "Q1–Q3 2027" means the months field wasn't computed from
  the window it sits next to.
